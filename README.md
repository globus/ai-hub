# @globus/ai-hub

We're exploring the intersection of research data and agents &mdash; sharing our findings along the way.

## Initiatives

| Initiative            | Status         | Description                                                                                                             | Resources                                            |
| --------------------- | -------------- | ----------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| Agent Skills          | In Development | Persona-shaped skills for researchers, administrators and developers with proven effectiveness.                         | [`./packages/agent-skills`](./packages/agent-skills) |
| Platform Improvements | Investigating  | From documentation to core services we want to make sure the Globus platform is ready for agents.                       |                                                      |
| MCP Server            | Investigating  | Globus exposed over the Model Context Protocol, officially, so any client can interact with the platform.               |                                                      |
| Knowledge Sharing     | Ongoing        | Sharing design patterns, best practices, and lessons learned from our work, so that others can build on our experience. |                                                      |

## Community Feedback

Understanding how institutions and labs are adopting agentic workflows helps drive our direction &mdash; **please consider [sharing your feedback](https://github.com/globus/ai-hub/issues/new?template=feedback.yml)**.
